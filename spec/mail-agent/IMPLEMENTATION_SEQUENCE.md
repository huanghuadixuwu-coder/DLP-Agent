## M6: UI Integration

Status: completed

- Keep `8511` as the user workspace: inbox, thread, draft review, explicit confirmation, outbound safety confirmation, and simplified task progress.
- Add `8512` governance console: high-risk exception approval/rejection, task timeline, provider health, queue health, recovery observations, DLQ replay, harness results, and diagnostics.
- Keep main answer generated by renderer.
- Keep debug and user-facing panels separated.
- Keep Prometheus as the metrics backend. Grafana is deferred.
- Add governance APIs for task stats, provider health, DLQ list/replay, and harness catalog.

Acceptance:

- `8511` can demonstrate one complete user-facing mail workflow.
- `8511` supports audited sender safety confirmation for medium-risk tasks.
- `8511` shows waiting-for-governance-review state for high-risk tasks without exception approval controls.
- `8512` can demonstrate governance approval, failure diagnosis, and one auditable recovery workflow.
- Critical-risk tasks are blocked by default.
- Prometheus metrics verify queue, latency, token, cost, and recovery behavior.

Validation:

- `docker compose exec -T api python -m compileall -q app scripts`
- `docker compose exec -T api python scripts/mail_m6_ui_governance_regression.py`
- `docker compose up -d --no-build governance-web`
- `http://localhost:8512/` returns 200.
